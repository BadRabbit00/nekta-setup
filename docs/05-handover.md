# Что передать в техподдержку Nekta

Установку и обновление Nekta Server выполняет вендор по SSH. Плейбуки готовят
систему, а этот список — то, что нужно отправить на **support@nekta.tech**,
чтобы установка не встала на полпути.

Часть данных плейбуки собирают сами:

```bash
ssh sysadm@nekta-01 sudo cat /etc/nekta/install-info
```

## Доступ к серверу

- IP или доменное имя
- Порт SSH и список всех перенаправленных портов
- Логин и пароль

Требования вендора к паролю (часть спецсимволов ломает их автоматизацию):

```
рекомендуемые:     ! @ * ( ) — _ + =
нерекомендуемые:   » # $ % & ' , . / : ; < > ? [ \ ] ^ ` { | } ~
```

SSH на время установки должен быть доступен **из интернета** — через VPN
вендор не работает.

## Доступ к веб-интерфейсу

- URL: доменное имя, внешний или внутренний IP. Для домена заранее настройте
  A-запись на адрес сервера
- Адрес электронной почты администратора системы

## Исходящая почта

- Название компании (подставляется в тему и текст писем)
- Адрес электронной почты и пароль
- Адрес почтового сервера и порт
- Защита соединения: SSL, TLS или отсутствует

## Глубина хранения данных

Сколько хранить показания — от этого зависит расчёт диска
([01-sizing.md](01-sizing.md)).

## Персональный дизайн (дополнительная услуга)

- Название компании — заголовок вкладки браузера
- Логотип 330×95 px, PNG или SVG, прозрачный фон — страница авторизации
- Логотип 150×20 px, PNG или SVG, прозрачный фон — верхняя панель
- Favicon 32×32 px, PNG, прозрачный фон
- Фоновая картинка 1920×1080 или 1920×1200 px
- HEX-коды: основной цвет (верхнее меню), вторичный (выбранный раздел),
  цвет кнопок, цвет активных элементов, цвет фона (если нет картинки)
- Доменное имя — **обязательно** для применения персонального дизайна
- Сертификат для домена — по желанию

## Перед отправкой

```bash
ansible-playbook playbooks/preflight.yml
```

Плейбук проверит соответствие железа профилю нагрузки и доступность внешних
ресурсов вендора. Отправлять заявку имеет смысл, когда обе проверки чистые:
иначе установка упрётся в закрытый порт или нехватку диска уже на стороне
вендора.
